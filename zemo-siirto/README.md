# ZEMO SIIRTO – platform prototype

*Your car. Our driver. Your destination.* – Auton siirto Suomessa, luotettavasti.

Static site, no build step. Every page has its own `index.html`; all pages share `app.js` + `style.css`
and the same data (browser localStorage).

```
zemosiirto.fi
├── /                      landing page + instant price
├── customer/  login · dashboard · create-order · tracking
├── driver/    login · available-jobs · my-jobs · inspection · navigation · earnings · profile
└── admin/     login · dashboard · drivers · customers · orders · pricing · payments · settings
```

`/customer/`, `/driver/` and `/admin/` redirect to the portal's start page; every page except `login`
redirects to the login when signed out. Pages are generated by `tools/build_pages.py`.

## Try it
1. Serve the folder (`python3 -m http.server` inside `zemo-siirto/`) or open `index.html` directly.
2. Open `/admin/login/` – the first visit creates the admin account.
3. Admin → Settings → **Load demo data** (password for demo accounts: `demo1234`).

## Order flow
Customer creates order → pays → admin/driver: driver accepts → **pickup inspection** → navigation → start driving
→ **delivery inspection** (new damage is flagged) → delivered → driver earnings → admin marks payout.

> Prototype: logins are client-side and payments are simulated. Before going live add a backend + database,
> real authentication, and a payment provider (e.g. Stripe or Paytrail).
